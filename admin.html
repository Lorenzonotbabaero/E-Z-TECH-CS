Connect

Changes are saved to your GitHub repository, and Render then updates the website automatically (about one minute).

How to get a token
  1. On GitHub, open Settings, then Developer settings, then Personal access tokens, then Fine-grained tokens.
  2. Generate a new token. Under Repository access, choose only this website’s repository.
  3. Under Permissions, set Contents to Read and write.
  4. Copy the token and paste it above. It stays in this browser tab only and is cleared when you close it.
